Placeholders for metamodels

- This folder should contain registered EMF/Ecore metamodels for `UML` and `AST` used by ATL.
- Typical files: `UML.ecore`, `AST.ecore` or registered plugin URIs.

Before running ATL:
- Ensure the UML metamodel expected by your ATL module matches the XMI produced by `tools/exportToXMI.js` or adjust the exporter accordingly.
